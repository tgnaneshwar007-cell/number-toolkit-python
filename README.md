# 🔢 Number Toolkit

A beginner-friendly Python CLI project built from the concepts I learned today.

## 📌 Concepts Used

- Conditional statements
- Nested if-else
- Tuples
- Tuple filtering
- For loops
- Range function
- Tuple unpacking
- Extended unpacking using *
- Dictionaries
- Two Sum / pair searching

## 🚀 Features

- Store numbers in a tuple
- Display original values
- Find even numbers
- Find odd numbers
- Calculate total sum
- Find a pair matching a target
- Display tuple information
